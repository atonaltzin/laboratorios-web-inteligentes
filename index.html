Acerca del proyecto

¿Cuál es el objetivo de este repositorio?

Reunir recursos interactivos que permitan transformar conceptos abstractos de Machine Learning en experiencias prácticas accesibles desde un navegador web.

Objetivo

Aprender mediante la resolución

Los simuladores buscan que el usuario interprete información, tome decisiones, construya soluciones y reciba retroalimentación durante el proceso, en lugar de limitarse a observar una explicación teórica.

¿A quién va dirigido?

Más allá del aula

  • Estudiantes que comienzan con Machine Learning y TensorFlow.js.
  • Docentes interesados en actividades interactivas.
  • Personas que desean explorar conceptos básicos de IA de forma práctica.
  • Desarrolladores e investigadores educativos interesados en simuladores y analítica de aprendizaje.
Metodología

Observar → representar → comprobar

Cada laboratorio parte de un fenómeno o problema, solicita una representación o decisión y proporciona retroalimentación. Algunos recursos registran intentos, pistas, tiempo y tipos de error para estudiar el proceso de aprendizaje.

Tecnologías

Web abierta y accesible

Los recursos se desarrollan principalmente con HTML, CSS y JavaScript. Conforme avance la colección se incorporarán experiencias con TensorFlow.js y modelos de Machine Learning ejecutados desde el navegador.
